Document Management System

A focused workspace for PDFs, search, and fast reading

This project combines upload, OCR processing, search, document metadata, comments, and a reader mode into one clean workflow. It is designed for structured document collections rather than generic file storage.

Core Features

PDF Upload OCR Processing Search Metadata Comments Reader Mode

User Access

Every standard user has a separate PDF pool. Admin accounts can review all assigned documents and inspect ownership across users from the dashboard.

System Overview

Frontend
Static UI served via Nginx with dashboard, document details, and reader pages.
Backend
Spring Boot REST API with session-based authentication and role handling.
Storage
PostgreSQL for metadata, MinIO for PDF files, Elasticsearch for search indexing.
Processing
RabbitMQ and worker services orchestrate OCR and text extraction in the background.
