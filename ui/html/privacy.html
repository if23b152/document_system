Data Protection

Privacy Overview

This overview explains which data is processed in the project and for what purpose. It is still a project template and should be legally reviewed before public deployment.

Processed Data

Username Email PDF Metadata Comments OCR Text

Purpose

The data is processed to support uploads, document ownership, OCR-based search, metadata editing, comments, and reading workflows inside the system.

Technical Storage

User Data
Stored in PostgreSQL and used for authentication and role handling.
Files
PDF files are stored in object storage and linked to users through metadata.
Search
Extracted text is indexed for full-text search.
Session
Authentication is handled through a server-side browser session.
